# copyReminder
复制导出网页版icloud中的reminder列表

## 概要
用于ios icloud 复制提醒事项
先打开提醒事项官网：https://www.icloud.com.cn/reminders/ （中国区）或者 https://www.icloud.com/reminders/ 
登录以后，进入需要复制的提醒事项列表，点击右上角"copy content" 即可完全复制提醒事项列表
在需要的word文档中粘贴即可实现导出。

Used for ios icloud to copy reminders
First open the official website of reminders: https://www.icloud.com.cn/reminders/  (China region) or https://www.icloud.com/reminders/
After logging in,enter the reminder list you need to copy, click "copy content" in the upper right corner to completely copy the reminder list
Paste it in the required word document to export.
